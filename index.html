QSS / Cleanse / Mikael — LoL

Quicksilver Sash, Cleanse & Mikael's Blessing : sur quel sort ça marche ? Mikael se lance sur un allié (ou soi).

QSS enlève tout sauf Airborne (knockup / pull), Suppression, Stase. N'enlève pas Ignite / Exhaust.
Cleanse enlève pareil + Ignite / Exhaust. N'enlève pas Airborne, Suppression, Stase.
Mikael (Purify) enlève tout sauf Airborne, Blind, Disarm, Nearsight, Suppression. Sur allié ou soi + heal 100–250. Ne sort pas de Morde R, n'enlève pas Ignite.

Légende rapide

  • ✓ = ça enlève. ✗ = ça n'enlève pas.
  • Airborne = knockup, knockback, pull, suspension (Yasuo, Alistar, Blitz, Janna…). Rien ne l'enlève.
  • Suppression = Malzahar R, Warwick R, Skarner R, Urgot R, Tahm W. Rien ne l'enlève.
  • Stase = Zhonya, Bard R, Lissandra R sur soi. Inenlevable.
  • Spécial = Illaoi E : QSS oui, Cleanse non, Mikael non. Mordekaiser R : rien ne marche depuis patch 14.8.
  • Summoner = Ignite, Exhaust : Cleanse oui, QSS non, Mikael non.
  • Mikael = comme QSS mais ne marche pas sur Blind, Disarm, Nearsight (Teemo Q, Quinn Q, Graves W, Irelia R). Se lance sur allié.

Données simplifiées patch récent. En cas de doute : airborne / suppression / stase = non.
